# Security Policy

## Supported versions

Only the latest published version of each `@metal/*` package receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, email **gabriel@frontal.dev** with:

- A description of the vulnerability
- Steps to reproduce
- Affected packages/versions
- Any known mitigations

You will receive an acknowledgement within 72 hours. A fix and disclosure timeline will be coordinated with you.
